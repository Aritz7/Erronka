# Dokumentazio Webgunea

Ongi etorri gure **1. Erronkako** dokumentazio-orrialde nagusira.

Webgune honetan, erronkan zehar garatutako lan guztiaren dokumentazioa, txosten teknikoak, prozesuak eta ikasitako kontzeptuak bildu eta kudeatzen ditugu. Proiektuaren jarraipena egiteko eta informazio guztia leku bakar batean ordenatuta izateko gunea da hau.

## Webgunearen Atal nagusiak

Goiko menuan nabigatuz, atal bakoitzean egindako lana aurkituko duzu:

* **Erronka:** Proiektuaren orri nagusia eta ikuspegi orokorra.
* **Datu-Baseak:** ER diagramak, eredu erlazionalak eta datu-basearen inplementazioa.
* **Markatze Lengoiak:** Webgunearen egitura, estiloak eta garapena.
* **Digitalizazioa:** Planifikazioaren kudeaketa, IT/OT teknologiak, TGDak eta Cloud Computing.
* **Sareak:** Sare-konfigurazioak, diagramak eta kodifikazioak.
* **Sistemak:** Makina birtualak, Windows Server, RAID egiturak eta babeskopiak.
